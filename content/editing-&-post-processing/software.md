# Photography Editing Software 

## Overview

Photography editing software allows photographers to organize, adjust, enhance, and export digital photographs. Editing programs can be used for simple adjustments such as cropping and brightness or more advanced tasks such as removing objects, creating masks, retouching portraits, and working with multiple layers.

Different editing programs are designed for different types of photographers. Some are beginner-friendly, while others provide advanced tools for professional photo editing.

---

## What Is Photography Editing Software?

Photography editing software is a computer or mobile application used to modify and manage digital photographs.

Common editing tasks include:

- Adjusting exposure
- Changing brightness and contrast
- Correcting color
- Cropping and straightening
- Removing unwanted objects
- Reducing noise
- Sharpening images
- Retouching portraits
- Applying lens corrections
- Creating masks and selections
- Organizing photographs
- Exporting images for different purposes

Editing software can help improve a photograph while still preserving the photographer's original image when non-destructive editing is used.

---

## Types of Photography Editing Software

### RAW Photo Editors

RAW editors are designed to process RAW files and make adjustments to photographs.

Common features include:

- Exposure adjustment
- White balance
- Highlight and shadow recovery
- Color correction
- Lens correction
- Noise reduction
- Sharpening
- Cropping
- Masking

RAW editors are commonly used as the first step in a photography editing workflow.

---

### Pixel-Based Photo Editors

Pixel-based editors allow photographers to make detailed changes to individual parts of an image.

Common features include:

- Layers
- Selection tools
- Clone tools
- Healing tools
- Text
- Background removal
- Object removal
- Advanced retouching
- Compositing

These programs are useful when photographers need more control than a basic RAW editor provides.

---

### Mobile Editing Apps

Mobile editing apps allow photographers to edit images using smartphones and tablets.

Common features include:

- Presets
- Exposure adjustments
- Filters
- Cropping
- Color adjustments
- Retouching
- Social media export

Mobile editors are useful for photographers who want to edit and share photographs quickly.

# Adobe Lightroom

Adobe Lightroom is designed for organizing and editing large collections of photographs.

### Common Features

- RAW processing
- Exposure adjustments
- White balance
- Color correction
- Cropping
- Presets
- Masking
- Noise reduction
- Sharpening
- Photo organization
- Batch editing

Lightroom is commonly used when photographers need to manage and edit many photographs efficiently.

---

# Adobe Photoshop

Adobe Photoshop is a powerful image-editing program that provides detailed control over individual parts of an image.

### Common Features

- Layers
- Masks
- Selections
- Object removal
- Retouching
- Background replacement
- Compositing
- Text
- Advanced color adjustments

Photoshop is useful when an image requires detailed manipulation beyond basic exposure and color adjustments.

---

# Capture One

Capture One is a professional photography editing and RAW-processing program.

### Common Features

- RAW processing
- Color grading
- Exposure adjustment
- Layers
- Masking
- Tethered shooting
- Photo organization
- Lens corrections

It is often used by photographers who want detailed control over color and RAW image processing.

# DxO PhotoLab

DxO PhotoLab is focused on RAW processing and image quality.

### Common Features

- RAW processing

- Sharpening

- Local adjustments

# Affinity Photo

# GIMP

### Common Features

- Layers
- Selection tools
- Filters
- Retouching
- Color adjustments

GIMP can be useful for photographers who want advanced editing tools without purchasing commercial software.
